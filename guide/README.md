# Maylang language reference

This is a multi-page React documentation website powered by Vite. From this
directory, install the Node dependencies and run the dev server:

```sh
npm install
npm run dev
```

Create a production build with `npm run build`. The examples target the strict
self-hosted compiler; see [`../docs/STRICT.md`](../docs/STRICT.md) for precise
typing rules and limitations. Page content lives in `src/docs.js`, the
reference-style navigation and custom Maylang syntax highlighter live in
`src/main.jsx`, and styling is in `src/style.css`.
