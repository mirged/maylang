MayBrowser — a native HTML/CSS engine in Maylang

Hello, world.

This page is parsed, cascaded and laid out by a browser engine written entirely in Maylang, then rasterised with antialiased text. The CSS cascade supports selectors, classes, ids and the box model.

Features

  • Custom HTML tree builder
  • Selector matching and specificity
  • Block and inline layout with wrapping
  • Duktape JavaScript through FFI

Fonts are rasterised by a tiny native shim; everything else is Maylang.

Text wrapping

The inline formatting code measures every word with real font metrics and wraps at the content edge, aligning baselines across mixed font sizes. This paragraph is deliberately long so that it wraps across several lines inside the card while the margins and padding keep the measure readable.
