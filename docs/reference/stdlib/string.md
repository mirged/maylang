- **string.may** — String transformations and simple delimiter helpers.
- Availability: full Linux x86-64 runtime.
- Import: `import "string" as library;`.
- Signatures below reproduce the source, including dynamic `Any` boundaries; parameter order and types are the call contract.
- Visibility: only declarations marked `pub` are exported.
- Source: [implementation](../../../stdlib/string.may).
- Shared contracts: [mutation, errors, Unicode, numeric limits and supported runtimes](../../../stdlib/CONTRACTS.md).
- `words` splits ASCII space, tab, carriage return and newline, dropping empty fields.
- Padding requires a nonempty pad when growth is needed; multicharacter pads can overshoot width.
- `csv` is a simple comma split; use `csv_parse` from the csv module for quoted CSV.
- **is_empty** — `pub fun is_empty(s: Str) -> Bool` — Report whether `s` has no characters.
- **repeat** — `pub fun repeat(s: Str, n: Int) -> Str` — Repeat `s` `n` times.
- **capitalize** — `pub fun capitalize(s: Str) -> Str` — Uppercase the first character, leaving the rest unchanged.
- **words** — `pub fun words(s: Str) -> List<Str>` — Split on ASCII space/tab/newline/carriage return, dropping empty pieces.
- **lines** — `pub fun lines(s: Str) -> List<Str>` — Split `s` into lines.
- **csv** — `pub fun csv(s: Str) -> List<Str>` — Split a comma-separated line, trimming each field.
- **reverse_str** — `pub fun reverse_str(s: Str) -> Str` — Return the characters of `s` in reverse order.
- **pad_left** — `pub fun pad_left(s: Str, width: Int, ch: Str) -> Str` — Left-pad `s` with `ch` until it is `width` characters wide.
- `pad_left` explicit fault strings: `"padding must not be empty"`; runtime/callback faults can also propagate.
- **pad_right** — `pub fun pad_right(s: Str, width: Int, ch: Str) -> Str` — Right-pad `s` with `ch` until it is `width` characters wide.
- `pad_right` explicit fault strings: `"padding must not be empty"`; runtime/callback faults can also propagate.
- **starts_with_any** — `pub fun starts_with_any(s: Str, prefixes: List<Str>) -> Bool` — Report whether `s` begins with any of `prefixes`.
- **count_occurrences** — `pub fun count_occurrences(s: Str, needle: Str) -> Int` — Count non-overlapping occurrences of `needle` in `s`.
- **truncate** — `pub fun truncate(s: Str, width: Int, ellipsis: Str) -> Str` — Shorten `s` to `width` characters, appending `ellipsis` when truncated.
