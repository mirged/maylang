- **string.may** — String transformations and simple delimiter helpers.
- Availability: full Linux x86-64 runtime.
- Import: `import "string" as library;`.
- Signatures below reproduce the source, including dynamic `Any` boundaries; parameter order and types are the call contract.
- Visibility: only declarations marked `pub` are exported.
- Source: [implementation](../../../stdlib/string.may).
- Shared contracts: [mutation, errors, Unicode, numeric limits and supported runtimes](../../../stdlib/CONTRACTS.md).
- `words` splits ASCII space, tab, carriage return and newline, dropping empty fields.
- Padding requires a nonempty pad when growth is needed; multicharacter pads can overshoot width.
- `csv` is a simple comma split; use `csv_parse` from the csv module for quoted CSV.
- **is_empty** — `pub fun is_empty(s: Any) -> Any` — Whether `s` has no characters.
- **repeat** — `pub fun repeat(s: Any, n: Any) -> Any` — `s` repeated `n` times.
- **capitalize** — `pub fun capitalize(s: Any) -> Any` — Uppercase the first character, leaving the rest unchanged.
- **words** — `pub fun words(s: Any) -> Any` — Split on ASCII space/tab/newline/carriage return, dropping empty pieces.
- **lines** — `pub fun lines(s: Any) -> Any` — The lines of `s`.
- **csv** — `pub fun csv(s: Any) -> Any` — Split a comma-separated line, trimming each field.
- **reverse_str** — `pub fun reverse_str(s: Any) -> Any` — The characters of `s` in reverse order.
- **pad_left** — `pub fun pad_left(s: Any, width: Any, ch: Any) -> Any` — Left-pad `s` with `ch` until it is `width` characters wide.
- `pad_left` explicit fault strings: `"padding must not be empty"`; runtime/callback faults can also propagate.
- **pad_right** — `pub fun pad_right(s: Any, width: Any, ch: Any) -> Any` — Right-pad `s` with `ch` until it is `width` characters wide.
- `pad_right` explicit fault strings: `"padding must not be empty"`; runtime/callback faults can also propagate.
- **starts_with_any** — `pub fun starts_with_any(s: Any, prefixes: Any) -> Any` — Whether `s` begins with any of `prefixes`.
- **count_occurrences** — `pub fun count_occurrences(s: Any, needle: Any) -> Any` — Count non-overlapping occurrences of `needle` in `s`.
- **truncate** — `pub fun truncate(s: Any, width: Any, ellipsis: Any) -> Any` — Shorten `s` to `width` characters, appending `ellipsis` when truncated.
