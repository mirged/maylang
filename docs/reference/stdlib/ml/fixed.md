- **ml/fixed.may** — Typed fixed-point dense neural inference with softsign activation.
- Availability: full Linux x86-64 runtime; experimental API.
- Import: `import "ml/fixed" as library;`.
- Signatures below reproduce the source, including dynamic `Any` boundaries; parameter order and types are the call contract.
- Visibility: all top-level declarations are exported because this module has no `pub` declarations.
- Source: [implementation](../../../../stdlib/ml/fixed.may).
- Shared contracts: [mutation, errors, Unicode, numeric limits and supported runtimes](../../../../stdlib/CONTRACTS.md).
- Parameters are output-major weights followed by biases for each layer. Inputs, parameters and outputs use the chosen integer scale.
- **FixedLayer** — `struct FixedLayer { inputs: Int, outputs: Int, offset: Int }` — Typed layer descriptor with input/output widths and an offset into the shared parameter list.
- **FixedNetwork** — `struct FixedNetwork { layers: List<FixedLayer>, parameters: List<Int>, scale: Int }` — Typed network containing layer descriptors, integer parameters and a positive integer scale.
- **nn_fixed_model** — `fun nn_fixed_model(dimensions: List<Int>, parameters: List<Int>, scale: Int) -> FixedNetwork` — Validate dimensions, scale and output-major weights/biases; return a FixedNetwork. Scale is 1..32768, widths 1..1024 and absolute parameters at most 16*scale.
- `nn_fixed_model` explicit fault strings: `"invalid fixed neural dimensions or scale"`, `"invalid fixed neural layer width"`, `"fixed neural parameter count mismatch"`, `"fixed neural weight exceeds safe range"`; runtime/callback faults can also propagate.
- **nn_fixed_predict** — `fun nn_fixed_predict(network: FixedNetwork, row: List<Int>) -> List<Int>` — Return integer-scaled output values using softsign activation; validate input width and absolute input at most 16*scale; share network parameters without mutation.
- `nn_fixed_predict` explicit fault strings: `"fixed neural input width mismatch"`, `"fixed neural input exceeds safe range"`; runtime/callback faults can also propagate.
