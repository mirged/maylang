- **ml/nn.may** — Dense neural layers, inference, backpropagation and snapshots.
- Availability: full Linux x86-64 runtime; experimental API.
- Import: `import "ml/nn" as library;`.
- Signatures below reproduce the source, including dynamic `Any` boundaries; parameter order and types are the call contract.
- Visibility: all top-level declarations are exported because this module has no `pub` declarations.
- Source: [implementation](../../../../stdlib/ml/nn.may).
- Shared contracts: [mutation, errors, Unicode, numeric limits and supported runtimes](../../../../stdlib/CONTRACTS.md).
- Layers contain weights, bias, activation, input/output dimensions, forward caches and gradients. Training mutates these maps.
- Supported dense activations are linear, relu, sigmoid, tanh and row-wise softmax.
- nn_predict updates caches; nn_predict_one performs cache-free single-row inference.
- **nn_model** — `fun nn_model() -> Any` — Return an empty dynamic model `{layers: [], input_dim: 0, output_dim: 0}`.
- **nn_add_dense** — `fun nn_add_dense(model: Any, input_dim: Any, output_dim: Any, activation: Any, rng: Any) -> Any` — Append a dense layer with random initialization and zero biases; validate positive compatible dimensions; mutate and return model.
- `nn_add_dense` explicit fault strings: `"dense dimensions must be positive"`, `"unsupported dense activation: "`, `"dense layer input does not match previous output"`; runtime/callback faults can also propagate.
- **nn_sigmoid** — `fun nn_sigmoid(x: Any) -> Any` — Return sigmoid after clamping its input to [-60,60].
- **nn_activate_scalar** — `fun nn_activate_scalar(x: Any, name: Any) -> Any` — Apply `linear`, `relu`, `sigmoid` or `tanh`; reject unknown scalar activation names.
- `nn_activate_scalar` explicit fault strings: `"unsupported activation: "`; runtime/callback faults can also propagate.
- **nn_activate_row** — `fun nn_activate_row(row: Any, name: Any) -> Any` — Apply scalar activation to a row or use stabilized `softmax` for a full row.
- **nn_forward** — `fun nn_forward(model: Any, batch: Any) -> Any` — Return output rows while storing each layer's input and output caches for backpropagation.
- `nn_forward` explicit fault strings: `"network needs at least one dense layer"`, `"network input width does not match first layer"`; runtime/callback faults can also propagate.
- **nn_activation_delta** — `fun nn_activation_delta(layer: Any, grad: Any, batch_index: Any, output_index: Any) -> Any` — Return the activation-adjusted gradient for one cached batch/output element, including the softmax Jacobian.
- `nn_activation_delta` explicit fault strings: `"unsupported activation derivative: "`; runtime/callback faults can also propagate.
- **nn_backward** — `fun nn_backward(model: Any, output_gradient: Any) -> Any` — Populate gradient weights/biases from the last forward caches; propagate the gradient backward and return model.
- **nn_predict** — `fun nn_predict(model: Any, rows: Any) -> Any` — Run `nn_forward` for input rows; update training caches.
- **nn_predict_one** — `fun nn_predict_one(model: Any, row: Any) -> Any` — Predict one row without training caches or intermediate product lists. Useful for repeatedly evaluating small controllers in simulations.
- `nn_predict_one` explicit fault strings: `"network needs at least one dense layer"`, `"network input width does not match layer"`; runtime/callback faults can also propagate.
- **nn_tensor_rows** — `fun nn_tensor_rows(t: Any) -> Any` — Convert a rank-two tensor to nested rows; reject other ranks.
- `nn_tensor_rows` explicit fault strings: `"neural network tensor input must be rank 2"`; runtime/callback faults can also propagate.
- **nn_predict_tensor** — `fun nn_predict_tensor(model: Any, t: Any) -> Any` — Return a tensor matrix of predictions, updating forward caches.
- **nn_forward_tensor** — `fun nn_forward_tensor(model: Any, t: Any) -> Any` — Convert a matrix tensor to rows, run forward and return matrix tensor outputs.
- **nn_backward_tensor** — `fun nn_backward_tensor(model: Any, gradient: Any) -> Any` — Convert matrix tensor gradients to rows and run backward; return model.
- **nn_parameter_count** — `fun nn_parameter_count(model: Any) -> Any` — Return the sum of dense weights and biases across all layers.
- **nn_state_dict** — `fun nn_state_dict(model: Any) -> Any` — Return layer states containing weights, bias, activation and dimensions for JSON snapshots.
- **nn_load_state** — `fun nn_load_state(model: Any, states: Any) -> Any` — Validate layer counts/dimensions and assign state weights/biases into the existing model; return model.
- `nn_load_state` explicit fault strings: `"model state layer count mismatch"`, `"model state layer configuration mismatch"`; runtime/callback faults can also propagate.
