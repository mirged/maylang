# Platform experiments

Larger systems built on the Maylang toolchain. They have native dependencies
beyond the core compiler; each README lists them.

| Project | Purpose | Start here |
| --- | --- | --- |
| [maybrowser](maybrowser/README.md) | Graphical browser, HTML/CSS engine, JavaScript, and PNG export | `make test-browser` |
| [mayos](mayos/README.md) | Bootable Maylang OS and kernel development example | `make -C platform/mayos` |
